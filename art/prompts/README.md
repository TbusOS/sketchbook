# 出图记录

出图模型不能按种子复现同一张图,所以每张图的提示词、附的参考图、验收结论都记在这里。
要重画时用同样的提示词和参考图,结果会相近,不会一模一样。

- 模型:本机 Codex CLI 0.159.3,`codex exec -m gpt-6-astra`,2026-10-10
- 命令:`scripts/illo.sh`(提示词走标准输入;已经画好的会跳过,中断后重跑就是续画)
- 画风参考 `ref-style.png`:sky-skills `demos/graphite-design/media/hero.webp` 转成的 PNG
  (sky-skills commit `99b234c`),角色(蓝毛衣扎发髻的女孩、灰色圆头机器人)也来自这张
- 原图在 `.cache/illo/`(不进仓库),`scripts/art-import.mjs` 转成 `art/source/*.webp`
